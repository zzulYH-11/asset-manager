## 🛠 Tech Stack

### Frontend

- React (v19)
- Vite (v8)
- Chart.js & react-chartjs-2 (자산 포트폴리오 차트 시각화)
- Font Awesome (아이콘)

### Backend

- Spring Boot (Java)
- Gradle

### Database

- PostgreSQL (JPA / Hibernate)

## 📂 Project Structure

```
project
├── .agents/       # AI 개발 에이전트 전용 규칙 및 스킬 정의
