# MVP

## 목표

거시경제에 집중하는 한국인 미국주식 장기 투자자를 위한 자산 관리 서비스를 만들자

---

## 포함 기능

- 미국 주식 CRUD 기능
- 거시경제 관련 주요 뉴스 10개 보여주기
- 미국 10년물 국채금리, 달러 인덱스, 원-달러 환율, 공포지수, WTI 원유, 금, 비트코인, S&P, 나스닥 지수

---

## 제외 기능

- 회원가입 / 로그인
- 보유 주식 가격 실시간 반영
- 총 자산 일별 변화 그래프 제공

---

## 성공 기준

- 미국 주식 CRUD 가능
- 외부 api로 가져온 뉴스 10개 조회 가능
- 외부 api로 가져온 지수 10개 조회 가능

---

## MVP 구현 완료 후 향후 계획

v1 - 배포

v2 - 회원가입 / 로그인 기능 붙이기

v3 - 총 자산 일별 변화 그래프 제공
