# MVP

## 목표

거시경제에 집중하는 한국인 미국주식 장기 투자자를 위한 자산 관리 서비스의 최소 기능을 구현해보자.

---

## 포함 기능

- 사용자가 보유한 미국 주식 CRUD
- 사용자가 입력한 평균 매입 단가 기준 총 자산 평가액 명시 및 종목별 비중 원형 차트로 시각화
- 거시경제 관련 주요 뉴스 10개 보여주기
- 글로벌 시장 지표 9종 (미국 10년물 국채금리, 달러 인덱스, 원-달러 환율, 공포지수, WTI 원유, 금, 비트코인, S&P, 나스닥 지수) 보여주기

---

## 제외 및 향후 추가할 기능

- 회원가입 / 로그인
- 보유 주식의 실시간 가격 자동 연동
- 포트폴리오 총액의 변화 추이(일별, 주별, 월별)를 추적 관찰 가능한 그래프 페이지
- 등록한 키워드 관련 뉴스가 나오면 알림 보내주는 기능
- 장기 투자자가 볼만한 뉴스 소팅해주기
- 보유 종목 관련 뉴스 모아서 보여주는 기능
- 시드 목표 설정 / 현황 보여주기
- 장기 투자 명언 보여주기
- 보유 자산 가격에 환율 적용하기
- 전일 시황 요약 보고서(간단하게) 제공

---

## 성공 기준

- 미국 주식 CRUD 가능
- 외부 API로 가져온 뉴스 10개 조회 가능
- 외부 API로 가져온 지표 9개 조회 가능
